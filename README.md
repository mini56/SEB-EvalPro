# SEB EvalPro

SEB EvalPro est la version desktop du plateau technique SEB.

## Principes du projet

- conserver strictement l'identité visuelle institutionnelle du plateau existant (couleurs, style, images et organisation visuelle) ;
- fonctionner sans dépendre de Firefox ou d'un navigateur installé sur le poste ;
- fonctionner hors connexion ;
- s'ouvrir directement en plein écran ;
- sauvegarder automatiquement et durablement la progression, les réponses, scores, temps et données candidat ;
- permettre la reprise exacte d'une évaluation interrompue ;
- proposer un accès Administrateur protégé pour consulter/récupérer le bilan ;
- conserver les exercices existants, avec une refonte technique ciblée de l'éditeur de texte `nwtexte` afin de fiabiliser ses fonctions.

Le développement desktop est réalisé sur une branche dédiée avant validation.

🏙️ Puzzle Gratte-ciel

C'est la journée de cohésion d'équipe, régulièrement l'équipe est invitée à se retrouver pour partager un moment convivial.
À cette occasion, la cheffe d'équipe a préparé un petit défi ! Elle propose à chacun une grille à compléter.

📋 Règles du jeu

  • • Placez les chiffres 1, 2, 3, 4 dans chaque case
  • • Chaque chiffre doit apparaître une seule fois par ligne et par colonne
  • • Les nombres sur les bords indiquent combien de "bâtons" sont visibles depuis ce point
💡 Exemple : Pour la rangée [2, 4, 3, 1] :
👈 Depuis la gauche, on voit 2 bâtons (le 2 et le 4, car le 4 cache le 3 et le 1)
👉 Depuis la droite, on voit 3 bâtons (le 1, le 3 et le 4)
🎯 Astuces :

• Si l'indice est 1, le plus grand bâton (4) doit être en première position !
• Si l'indice est 4, les bâtons sont forcément dans l'ordre croissant : 1, 2, 3, 4
• Commencez par les indices les plus contraignants (1 et 4)
🎮 Comment jouer :

• Remplissez toutes les cases avec des chiffres de 1 à 4
• Cliquez sur "Valider" pour vérifier votre réponse
• Une fois terminé, cliquez sur "Page suivante"

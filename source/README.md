# Source du plateau

Déposer ici l'archive originale sous le nom exact :

`QCM.zip`

Le ZIP reste la référence visuelle et fonctionnelle d'origine. Le script `scripts/prepare-web.js` l'extrait automatiquement dans `app/web/` avant lancement ou compilation.

Les corrections futures qui doivent volontairement remplacer un fichier du ZIP seront placées dans `overrides/`, afin de distinguer clairement le plateau original des modifications SEB EvalPro.
